The RAMSES sensor is a hyperspectral radiometer available on autonomous profiler 
able to provide downwelling irradiance / upwelling radiance at different wavelengths.
Up to now, it has been mounted on APEX and NKE CTS5 floats.
This repository has been set up to share programs to compute the hyperspectral radiometry wavelengths of the RAMSES sensor,
following recommendations on the Argo syntax of the PREDEPLOYMENT_CALIB_COEFFICIENT (of the metadata file ex: 3902759_meta_aux.nc )

you will find here :

- a R folder 

- a matlab folder
