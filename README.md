# RAMSES sensor hyperspectral radiometry wavelengths

The RAMSES sensor is a hyperspectral radiometer available on some autonomous profilers that is 
able to provide downwelling irradiance / upwelling radiance at different wavelengths.
Up to now, it has been mounted on APEX and NKE CTS5 floats.

This repository has been set up to share programs to compute the hyperspectral radiometry wavelengths of the RAMSES sensor, following recommendations on the Argo syntax of the PREDEPLOYMENT_CALIB_COEFFICIENT (of the metadata file ex: 3902759_meta_aux.nc)

In the R, Matlab and Python folders you will find the corresponding language implementations of codes to computation wavelengths.

These implementations have been inter-compared and provide similar results [TBD].
